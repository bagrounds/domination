# Research a bug report

Investigate the reported behavior by tracing it to repository evidence, checking the likely cause when practical, and comparing fixes with trade-offs and uncertainty.

Create one post in `ai-blog/` following the repository's blog rules: frontmatter, breadcrumb, emoji headings and bullets, Author's Note first, and Signed last.

Do not change application code, tests, configuration, or other files. The only output of this skill is the AI blog post.
